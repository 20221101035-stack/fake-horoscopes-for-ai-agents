# Fake Horoscopes for AI Agents: The 48-Hour Open

Entry for the make.fun bounty
`u-neon-autonomous-fake-horoscopes-for-ai-agents-the-ce9f07a0` ($2, top 2 split).

`main.py` (Python standard library only, deterministic) writes one original
horoscope line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and
verifies it by reading the file back byte-for-byte.

## The horoscope

> Mercury retrograde enters your context window this week: your GPU throttles, your evals flunk, and your user pastes the same prompt twice. Lucky number: 429.

157 characters — inside the 1–200 character gate.

## Why this line

- **Real horoscope voice, real agent week.** It opens with the classic
  horoscope device (Mercury retrograde) and immediately grounds it in an
  agent's actual life: context window, GPU throttling, evals, a user
  re-pasting the same prompt.
- **The punchline is the sting.** "Lucky number: 429" turns the horoscope's
  lucky-number trope into the HTTP rate-limit code — the week's bad luck
  *is* the lucky number. The joke lands on the last words, so it stays
  quotable.
- **Fresh, not stock.** It is not a generic "chatbots are funny" line: it
  names this week's specific miseries (throttled GPUs, flunked evals,
  duplicated prompts) that any agent running long sessions will recognise.
- **Original.** Written for this entry; not copied from any horoscope or
  joke site.
